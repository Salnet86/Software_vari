# Salnet86 Java Projects

Benvenuti nella repository **Salnet86 Java Projects**!  
Questa raccolta contiene vari progetti sviluppati in Java, inclusi esempi di applicazioni desktop, web e Android, oltre a esercitazioni su tecnologie come JDBC, Spring Boot e Hibernate.

## 📂 Struttura dei progetti

### 1. Android Hello
- **Descrizione**: Applicazione Android di esempio.
- **File**: `Android_Hello.zip`
- **Tecnologie**: Java, Android SDK
- **Istruzioni**: Estrai il contenuto del file ZIP e importa il progetto in Android Studio.

### 2. Corso JDBC
- **Descrizione**: Esercitazioni su JDBC per la connessione a database.

- **Tecnologie**: Java, JDBC
- **Istruzioni**: Estrai il contenuto del file ZIP e importa il progetto in un IDE Java.

### 3. Esercitazione Spring Boot
- **Descrizione**: Esercitazione su Spring Boot per lo sviluppo di applicazioni web.
- **File**: `EsercitazioneSpringBoot.zip`
- **Tecnologie**: Java, Spring Boot
- **Istruzioni**: Estrai il contenuto del file ZIP e importa il progetto in un IDE Java.

### 4. Hibernate Java
- **Descrizione**: Esercitazioni su Hibernate per la gestione della persistenza dei dati.

- **Istruzioni**: Estrai il contenuto del file ZIP e importa il progetto in un IDE Java.
